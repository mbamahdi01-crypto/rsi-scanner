# فلتر انفراج RSI — السوق السعودي (تاسي) والسوق الأمريكي

تطبيق ويب (Flask) يفحص الأسهم دورياً بنمط **"الانفراج + اختراق القمة/القاع على RSI"**
ويطلق تنبيهاً في اللحظة التي يخترق فيها RSI القمة (منطقة طلب / إشارة شراء)
أو يكسر القاع (منطقة عرض / إشارة بيع)، مع استخراج منطقة الطلب/العرض من فريم أعلى.

## ما الذي يغطيه الموقع

| السوق | النطاق | القطاعات |
|---|---|---|
| السوق السعودي (تاسي) | 266 سهم مدرج | القطاعات الرسمية الـ 21 (البنوك، الطاقة، المواد، التأمين، REITs...) |
| مؤشر تاسي | ^TASI.SR | خيار "المؤشرات" |
| السوق الأمريكي | S&P 500 + ناسداك 100 + داو 30 + أقوى أسهم راسل (~670 سهم) | قطاعات GICS الـ 11 |
| مؤشرات أمريكا | ^GSPC, ^IXIC, ^DJI | خيار "المؤشرات" |

### "أقوى أسهم راسل" — تحديث تلقائي
تُختار قائمة أسهم Russell 1000 تلقائياً من بيانات **iShares Russell 1000 ETF** الحية
(تحتوي على الأوزان الحقيقية للأسهم في المؤشر)، وتُضمَّن أفضلها وزناً في فحص
"كل القطاعات" للسوق الأمريكي. تُحدَّث هذه القوائم دورياً في الخلفية من المصادر:

- السعودية: tadawulallshareindex.com
- S&P 500 و Dow 30: ويكيبيديا
- ناسداك 100: مستودع GitHub محدّث تلقائياً
- Russell 1000: BlackRock

عند كل إقلاع يتحقق التطبيق من عمر القوائم المخزنة في `data/` ويحدّثها إن كانت
أقدم من 7 أيام. يمكنك أيضاً تحديثها يدوياً من زر **"تحديث قوائم الأسهم"**.

## التشغيل

```bash
# 1) تثبيت المتطلبات (يفضّل داخل بيئة افتراضية)
pip install -r requirements.txt

# 2) تشغيل التطبيق
python app.py
```

ثم افتح المتصفح على: **http://localhost:5000**

> بيانات `data/*.json` مولّدة مسبقاً، فالتطبيق يعمل فوراً بدون إنترنت باستثناء
> جلب أسعار الأسهم مباشرة من Yahoo Chart أثناء الفحص.

## الاستخدام

1. اختر **السوق**: السعودي (تاسي) أو الأمريكي.
2. اختر **القطاع**: كل القطاعات، قطاع محدد، أو "المؤشرات".
3. اختر **فريم التنفيذ**: 15 دقيقة / ساعة / يومي.
4. اضغط **فحص الآن**، أو فعّل **الفحص التلقائي** (دورة كل X دقيقة) مع زر
   **إيقاف** عندما تريد.
5. جدول النتائج يعرض: السهم، الاسم، السوق، القطاع، نوع الإشارة (طلب/عرض)،
   سعر الاختراق، قيمة RSI، المستوى المخترق، ونطاق منطقة الطلب/العرض من الفريم الأعلى.

خريطة الفريمات (فريم التنفيذ ← فريم منطقة الطلب/العرض):

```
15 دقيقة  ←  ساعتان (تُجمَّع تلقائياً من شموع الساعة)
ساعة      ←  يومي
يومي      ←  أسبوعي
```

## الملفات

| الملف | الوصف |
|---|---|
| `app.py` | تطبيق Flask: الإعدادات، الجدولة، الفحص الجماعي، قاعدة البيانات، الواجهات |
| `markets.py` | طبقة البيانات: قوائم الأسهم، القطاعات، الترجمة العربية، التحديث التلقائي |
| `scanner.py` | منطق كشف الانفراج واختراق RSI واستخراج منطقة الطلب/العرض |
| `build_data.py` | أداة جلب قوائم الأسهم والقطاعات من المصادر (تُستخدم للتحديث التلقائي) |
| `data/*.json` | القوائم المخزنة (سعودي، S&P 500، ناسداك 100، داو 30، راسل 1000) |
| `templates/index.html` | الواجهة العربية |
| `alerts.db` | قاعدة التنبيهات (SQLite، تُنشأ تلقائياً) |

## الإعدادات القابلة للتعديل (أعلى app.py)

| المتغير | الوصف |
|---|---|
| `RSI_PERIOD` / `PIVOT_LEFT` / `PIVOT_RIGHT` / `TOLERANCE` | معايير حساب RSI ونقاط القمم/القيعان التأرجحية |
| `TIMEFRAME_MAP` | خريطة فريم التنفيذ ← فريم منطقة الطلب/العرض |
| `YF_WORKERS` | عدد أسهم Yahoo Chart التي تُجلب بالتوازي (64 افتراضياً) |
| `YF_REQUEST_TIMEOUT` | مهلة جلب السهم الواحد حتى لا يعلق الفحص |
| `RUSSELL_STRONG_COUNT` (في markets.py) | عدد "أقوى أسهم راسل" المضمّنة |

## تنبيه

أداة تحليل فني آلية وليست توصية استثمارية. النتائج تعتمد على البيانات المجانية
ودقة تعريف القمم/القيعان التأرجحية، وقد تحدث إشارات خاطئة في الأسواق المتذبذبة.
راجع كل إشارة يدوياً على الشارت قبل اتخاذ أي قرار.
